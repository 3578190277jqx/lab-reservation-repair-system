# 实验室预约与报修微信小程序

使用微信开发者工具导入本目录，在 `project.config.json` 设置自己的 AppID，在 `config.js` 设置后端 `/api` 地址。手机上的 `127.0.0.1` 指向手机本身，真机调试应使用可达的开发服务地址。

小程序支持系统账号登录、学生注册、设备查询、预约取消及签到、报修与维修流转、通知与个人信息。不同角色的权限与实验室范围由共享后端校验。

正式发布需配置微信认可的 HTTPS request、uploadFile 和 downloadFile 合法域名。邮箱验证码与图片识别通过后端配置。当前登录使用系统账号。

运行 `node --test tests/*.test.js` 进行本地脚本检查，完整启动说明见项目根 README。
