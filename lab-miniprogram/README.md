# 实验室预约与报修微信小程序

独立原生微信小程序，与 Vue 网页端共用现有 Spring Boot 接口、账号、数据库。
本次仅修改 E:\codex\lab-miniprogram，保留网页端和后端。

## 已实现功能

- 三种角色账号密码登录、学生注册、个人资料查看、退出、Token持久化和过期处理。
- 设备搜索、状态筛选、分页；学生预约；所有角色提交故障报修。
- 学生查看个人预约、取消、签到；管理员查看管理范围预约、通过或拒绝申请。
- 学生查看个人报修；管理员查看管理范围工单、受理、开始维修、填写维修费用及完成说明。
- 图片上传、授权图片预览、维修流转记录、可选百度AI提示（使用已有后端配置）。
- 管理员统计总览；不同管理员的数据范围由后端执行权限校验。
- 网络错误、空列表、分页重试、重复提交防护、账号切换时丢弃旧请求。

完整网页后台继续可用。实验室/设备基础资料维护、用户角色分配和完整ECharts图表仍使用网页后台或既有后端接口；小程序当前提供移动预约与运维工作流、统计总览，不是全部后台界面的复制。

## 导入与启动

1. 先启动现有项目：运行 E:\codex\docker-deployment-20261003\一键部署.cmd；已有镜像只启动可运行 Start-Docker.ps1 -SkipBuild。
2. 微信开发者工具导入 E:\codex\lab-miniprogram，类型选“小程序”，无云开发；原生项目，无需npm install。
3. 在 project.config.json 中配置你自己的 AppID，并使用有权限的微信账号登录开发者工具。AppSecret 不放客户端。
4. config.js 默认访问 http://127.0.0.1:18088/api（Docker服务）。仅本机开发工具调试时，按工具要求启用开发环境不校验合法域名；正式发布保持域名检查。
5. 编译后登录网页端同一账号。学生在“设备”页申请预约或报修；管理员在“预约”“报修”页审核处理，在“我的”页查看统计。
6. 手机上的127.0.0.1指向手机自身。真机开发需要可达的电脑地址/调试域名；正式发布请将baseURL改为自己的HTTPS后端域名加/api，并在微信后台配置request、uploadFile、downloadFile合法域名。

微信网络说明：https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html
