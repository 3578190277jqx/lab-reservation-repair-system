# 验证范围

2026-11-11 发布候选副本的历史记录包含后端 136 项测试、前端 159 项测试及 lint、format:check、build。Ubuntu WSL 的 MySQL 8.0.46、Redis 7.4.12 隔离环境运行了 67 项真实业务与迁移检查和 3 项 CORS、登录限流检查。

业务检查覆盖登录与角色边界、预约审核、重叠与相邻时段并发、重复签到、维修状态流转、故障取消通知和事务回滚。迁移检查覆盖空库、明确接管的已知八表旧库、未知结构拒绝接管。

本次 GitHub 导出以当前源码为基础，合入该发布副本中的独立 Flyway 数据源配置及 Element Plus 加载反馈。历史记录不代表任意后续修改均已联调。第三方邮箱、短信和 AI 请求未包含在上述隔离检查中，小程序仍需通过开发者工具和真机验收。
